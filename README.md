# 傳說永恆

目前版本：`v0.2.9.2-alpha`

文字網頁 roguelite / 半 RPG 原型。玩家從安全據點選擇角色與地區，進行自動戰鬥冒險。現有可玩角色包含「冒險者」、旅途中解鎖的「弓箭手」，以及在安平鎮切磋後解鎖的「凱哥」；角色各自保存等級、EXP 與技能進度。死亡、撤退或通關後本輪結束，回到本輪出發據點重新整備。

## v0.2.9.2 高地戰術選招與岩石反制

高地招式先選取、就地看行動與風吹後果，再確認執行；點地點只篩招式，不消耗回合。危險格直接列攻擊來源，預覽亦顯示敵人可能互傷的收益。把正要衝撞的敵人推進現存岩石，可犧牲整塊共用岩打斷本次衝撞；沒有岩石則推不斷，不附加傷害或武器充能。

原地突入與已達兩格風的重複引風選項移除。第三戰起的風序開場會隨旅程種子變化，開戰即可看本／下回合，保存續玩不重抽；前兩戰保留教學節奏。

## v0.2.9.1 高地攻擊預告與祝福介面

敵人的落刀位置會先鎖定；風可能把你帶離攻擊，也可能吹進刀口。棋盤以劍與斜線標示攻擊欄，實心人表示現在、虛線圈表示行動吹風後；可先比較攻擊與守勢，預覽不消耗回合。追人攻擊另行標示，離開紅格不保證安全。

祝福卡固定呈現名稱、情境、效果、稀有度，依內容調整高度。18項高地祝福重新整理文案，並加入不被風吹的沉身守隘、把敵人推進攻擊的順勢推搡、拆岩增強當回合風力的破岩引風。敵人誤傷是否算玩家誘導，按實際推移或誘導衝撞判定，不會因隨意換位而領取獎勵。

## v0.2.9 斷風高地重製

完整通關海岸後開放，推薦 Lv.28～30。12 場戰鬥包含三次分岔與兩名首領；每回合依序處理玩家行動、共用風場與已預告敵意。三欄站位、有限耐久的擋風岩、拆岩與誘導互撞，形成與海岸不同的決策。介面提供風後落點預覽；獵道提高本段金幣倍率與非保底素材掉率（最高100%），不增加保底素材數量。

18 個祝福支援借風機會、穿隘、突進與有限戰術資源；每輪從 5 個事件中安排前後段各一個，選擇會改變下一戰地形。3 種整備改為有限次數的繩索、岩架與踏釘。高地有 7 項公會委託，包含拆岩與誘導互撞。

5 把地區武器改為可跨地區使用的反攻、蓄射、破勢、換手／三連、重量釋放；追加傷害不複製角色技能鏈。戰斧依武器類別決定裝備資格，未來持斧角色可沿用。首次通關可用舊武器完成。永久存檔維持 Schema 12；舊版本未完成旅程會要求先備份再結束，不直接套用新版規則。

## 開發工具

本專案另外提供獨立內容編輯器（目前版本：`content-editor v0.1.6`），用來建立與維護地區怪物、局中 Buff / 祝福資料。工具頁不會直接修改主遊戲存檔；但可匯出工具內容包 JSON，也可匯出能直接覆蓋 `src/data/regions/*.json` 的遊戲地區 JSON。

本機啟動靜態伺服器後，可開啟：

    http://127.0.0.1:4173/tools/content-editor.html

GitHub Pages 部署後，可開啟：

    https://drinkwateru.github.io/legend-eternal-web/tools/content-editor.html

目前工具版本記錄於 `tools/VERSION`。第一版工具支援地區內容包、怪物資料、局中 Buff / 祝福、單筆複製、整包 JSON 匯入與匯出。工具頁也可以載入目前專案內建的平原地區資料，或選擇本機的 `src/data/regions/*.json` 匯入成工具內容包，方便用既有地區資料繼續新增怪物與 Buff。

## 存檔

- 目前使用瀏覽器 `localStorage` 保存基礎統計與設定。
- 存檔 key 為 `legendEternalSave`。
- 遷移舊格式或確認匯入前，會將原始內容保存至 `legendEternalSave:recovery`，作為最近一次轉換／匯入前的復原副本；它不是每回合自動備份。
- 存檔資料使用英文 id，例如 `plains`、`adventurer`，避免之後顯示名稱調整時破壞存檔。
- 存檔包含 `schemaVersion`，版本更新時會盡量轉換舊資料，不直接重置。
- 統計數據頁可以用存檔碼匯出與匯入進度，方便更換裝置。
- 使用 Save Schema 12 保存 `activeRun`。出發與每次正式冒險操作會把目前回合、敵人、祝福選項、事件結果、海岸扎營與亂數狀態，連同永久獎勵一起保存。重整後可從主選單或營地「繼續冒險」，不會重抽或重新發獎。
- 有待續旅程時不會用新旅程覆蓋；經確認結束旅程才清除。死亡、撤退、完整通關或決鬥結束會清除對應快照；鳳凰加護與 Route 結尾可在尚未完成時恢復。存檔碼匯出／匯入也包含快照。
- 不同遊戲版本或不完整的快照不會自動執行，也不會清空永久進度；可先匯出備份，再經確認結束該旅程。
- 讀取異常時會保護原始存檔，停止自動覆寫並顯示下載原始資料的提示；不支援以舊版遊戲降版開啟較新格式的存檔。原始資料下載為 JSON，供人工復原，並非可直接匯入的存檔碼。
- 匯入必須保存成功才會切換目前進度；保存失敗可在同一視窗重試。
- 出發、戰鬥回合與結算、冒險事件獎勵、海灘段落紀錄及重要劇情解鎖，會將同一次玩家操作的永久變更合併保存；同回合擊殺的 EXP、掉落、委託與統計不會分開寫入。
- 上述操作保存失敗時，以對話框暫停後續操作並保留候選結果；重試不重跑戰鬥、不重抽掉落，也不重複扣款。出發須保存成功才切入冒險畫面，結算與劇情離場也會等待保存成功。玩家可經確認後放棄尚未提交的結果，重新載入最後已保存的旅程位置。
- 同一來源同時只允許一個新版分頁讀寫進度。其他分頁在存檔讀取／遷移前就會被攔住；關閉原分頁後，重新載入另一頁才能接續。更新時請先關閉舊版頁面；舊版程式不會遵守新的鎖定規則。
- 分頁鎖定需要支援 Web Locks 的瀏覽器與安全來源（正式站 HTTPS，或本機 localhost）。不支援時會停止進入遊戲，避免無保護地寫入；技術約束見 [Web Locks 規格](https://w3c.github.io/web-locks/#api)。
- 統計數據頁可以刪除存檔，只會刪除本遊戲的主存檔與復原副本；刪除或重建失敗會顯示實際結果。

## 執行方式

建議使用專案內建的 no-cache 開發伺服器，避免瀏覽器阻擋 ES modules，也避免舊版 CSS / JS 快取干擾測試：

```bash
python tools/dev-server.py
```

接著開啟 `http://127.0.0.1:4173/`。需要改 port 時可使用 `python tools/dev-server.py --port 4174`。

需要開啟調試面板時使用：

```text
http://127.0.0.1:4173/?debug=1
```

調試面板的「安全區測試」可將據點設為已解鎖未造訪、標記並前往、直接移動、重設據點、開啟選擇據點頁，或直接播放安平鎮首次抵達。這些操作會修改目前瀏覽器的正式存檔，測試前應先匯出備份。
「公會委託測試」可直接重播首次導覽、開啟委託欄，並把任一正式委託設為剛承接、半程或可回報狀態；也能清除目前委託或重設委託資料。這些操作同樣會修改正式存檔。
角色與存檔區另提供「給予鍛造資源」、「取得全部武器」與「清空全部武器」，方便測試鐵匠鋪、角色相容性與裝備流程；清空武器會同步卸下所有角色目前裝備。

## 版本與 Commit 方式

瀏覽器驗證腳本 `tools/verify-*-browser.cjs` 與 `tools/verify-ui-aesthetics.cjs` 另需 Python、Microsoft Edge 與可載入的 Playwright。預設載入 `playwright`；若使用外部安裝，可將 `PLAYWRIGHT_MODULE` 環境變數設為其模組絕對路徑。測試使用隔離瀏覽器與合成存檔；`verify-save-transactions-browser.cjs`、`verify-commerce-transactions-browser.cjs` 需先啟動 port 4186 的內建開發伺服器，其餘腳本會自行啟停伺服器。

- 小型 UI、文字、數值、戰鬥節奏調整可以先留在 working tree，不一定每次 commit。
- 當完成一個可描述的階段版本時，再整理成 commit 並更新版本號。
- 版本號採 `v主版.次版.修訂.熱修-alpha`。目前仍是早期原型，因此使用 `alpha`。
- `主版` 用於正式化或大型架構變更，例如 `v1.0.0.0`。
- `次版` 用於新增明顯系統，例如等級、金幣素材、城鎮商店。
- `修訂` 用於一批可描述的小功能或 UI 改善。
- `熱修` 用於超小 bugfix，例如 Pages 快取、按鈕失效、錯字或顯示錯誤。
- Commit message 以中文描述本次階段內容，例如 `角色：實裝弓箭手技能與多角色選單`。
